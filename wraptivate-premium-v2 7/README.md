# Wraptivate Premium Website Package — V2

This is a local website build for review, with nine dedicated service pages, shared branding, real Wraptivate project photography supplied by the client, location/coverage map, social icon placeholders, a finish explorer, and a project brief configurator.

## Preview
Open `index.html` in a modern browser. For best results, serve the folder with a local web server before testing embedded maps/video, because browsers may restrict some features when opened from `file://`.

## Included services
- Colour change vehicle wraps
- Printed vehicle wraps and graphics
- Partial vehicle wraps
- De-chroming and chrome delete
- Commercial vehicle signage and fleet graphics
- Race car liveries
- Roof wraps and accents
- Vehicle styling and body kits
- Paint protection film (PPF), with unique service copy, coverage options, FAQs and quote selection

## Included interactions
- Main hero uses the supplied BMW M240i image.
- Project gallery uses supplied Wraptivate vehicle photos.
- Finish explorer switches between real project examples and updates the project brief selections.
- Project brief form builds a pre-filled email addressed to brandon@wraptivate.co.uk; it does not send or store data by itself.
- Google Maps embed and directions links point to the supplied Thurnscoe/Rotherham business address.
- Social icon links are placeholders until official profile URLs are entered in `assets/site.js`.
- A public third-party wrapping-process video is embedded for demonstration; replace it with Wraptivate-owned footage before production launch.

## Before launch
1. Add official Instagram, Facebook, TikTok, YouTube, WhatsApp and LinkedIn URLs to `SOCIAL_LINKS` in `assets/site.js`.
2. Replace the third-party video with Wraptivate's own licensed/owned workshop footage if available.
3. Configure a real form endpoint/CRM if enquiries must submit without the visitor's email application.
4. Confirm the final advertised service coverage areas and business details.
5. Review all service copy, SEO metadata, accessibility and performance on the live hosting environment.

This package is a preview build and has not been deployed to wraptivate.co.uk.
